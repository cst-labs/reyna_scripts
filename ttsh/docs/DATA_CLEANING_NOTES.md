# NNI Cleaned Orders Export

The final NNI CSV is generated by `scripts/data_prep/export_nni_cleaned_orders.py`.

## Source Files

- `merged/ct_orders_cleaned.xlsx`, sheet `Imaging`
- Output: `data/nni_cleaned_orders.csv`

## Canonical Cleaned Data

`merged/ct_orders_cleaned.xlsx` is produced by `scripts/data_prep/clean_ct_orders.py`.

For CT imaging rows, that cleaning step:

- keeps rows whose `CSN` exists in `merged/all_pt_combined.xlsx`
- merges overlapping or identical exam windows for the same `CSN` and procedure category
- drops rows with missing parent order time, missing exam start, non-positive exam duration, or negative CT wait time
- assigns `Site` from the Performing Location parsed from `Ordering Question Responses`
- uses `brainbodysep.tsv` only when parsed Performing Location is empty
- when a merged row contains conflicting parsed sites, keeps the `Site` and `Procedure Location` from the original row with the earliest `Exam Start`

## Final NNI CSV Rules

Starting from the canonical cleaned imaging sheet:

1. Keep rows where cleaned `Site == "NNI"`.
2. Compute `scan_duration` from the chronologically ordered retained NNI scans:
   - If a scan's `Exam End` is before the next scan's `Exam Start`, use `Exam End - Exam Start + 17.9 minutes`.
   - If a scan's `Exam End` is at or after the next scan's `Exam Start`, use `next Exam Start - current Exam Start`.
   - Boundary rows without a valid next scan fall back to `Exam End - Exam Start`.
3. Drop rows where `scan_duration` is missing, negative, or zero. The final simulated-queue outputs are now generated on this final exported cohort.

The cleaned `Site` already encodes the Performing Location rule. If a merged row spans conflicting parsed sites, `scripts/data_prep/clean_ct_orders.py` sets `Site` and `Procedure Location` from the original row with the earliest exam start.
